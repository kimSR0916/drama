# drama

주행 시간을 하나의 이야기로 바꾸는 차량용 시나리오 서비스.

## 컨셉

기획 미팅 결론은 "시나리오 강화"다. 레퍼런스는 제타와 크랙 같은 캐릭터·시나리오 플랫폼이다.
일반 내비게이션과의 차별점은 경로, 정체, 운전 습관 같은 실제 주행 신호가 이야기의 사건이 된다는 점이다.

- 대상 유저: 출퇴근이나 장거리 운전을 반복하는 운전자, 캐릭터·시나리오 콘텐츠에 익숙한 20~30대.
- 차별점: 주행 시간(T)에 맞춰 이야기 분량이 자동 조절되고, 도착 1분 전에 소결말과 자동 저장이 이루어진다.
- 안전 원칙: 에어백 전개나 중대 충돌이 감지되면 모든 연출이 즉시 멈추고 SOS 모드로 전환된다.

## 워크플로우

1. 주행 전(P단). 모바일 앱에서 나만의 시나리오를 만들거나 차량 단말기에서 기본 테마를 고른다. 이어하기, 처음부터, 새로 시작 중 하나로 세션을 연다.
2. 주행 중. 주행 시간에 맞춘 페이싱으로 사건을 배치한다. 급가속·급제동에는 캐릭터가 반응하고, 정체 구간에는 세계관 안내와 선택지를 띄운다.
3. 도착. 1분 전 소결말과 스마트 세이브, P단 체결 시 제한 해제, 주행 리포트를 보여준다.

## 실행

```sh
npm install
npm run dev     # 시뮬레이터 (모바일 앱 · 차량 단말기 · 차량 신호 패널)
npm run check   # 타입 검사, 테스트, 빌드
```

## 구조

- `src/core`는 플랫폼과 무관한 엔진이다. 주행 전 세션 흐름(`predrive.ts`), 페이싱(`pacing.ts`), 주행 루프와 비상 브랜치(`drive.ts`), 리포트(`report.ts`)가 모두 이벤트를 받아 상태와 효과 목록을 돌려주는 순수 함수다. 차량 단말기(AAOS)로 옮길 때 이 계약을 그대로 쓴다.
- `src/authoring`은 모바일 시나리오 작성, 기본 테마, 계정별 저장소다.
- `src/web`은 화면설계서가 나오기 전 동작을 확인하는 시뮬레이터다.
